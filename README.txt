# ARQUIVO BLOQUEADO — Interface

Interface web inspirada no mockup enviado, usando:
- HTML5
- CSS3
- JavaScript (para a lógica da senha)
- Python (servidor local opcional)

## Senha atual
24/07/2002

A ordem foi montada conforme as pistas do projeto


## Como abrir

### Opção 1 — simples
Abra `index.html` diretamente no navegador.

### Opção 2 — com Python
1. Instale o Python 3.
2. Abra o terminal dentro desta pasta.
3. Execute:
   `python server.py`
4. Acesse:
   `http://127.0.0.1:8000`

## Estrutura
- `index.html` — interface
- `style.css` — visual, responsividade e animações
- `script.js` — senha e troca para a tela "Arquivo Recuperado"
- `server.py` — servidor local Python
- `assets/` — reservado para futuras imagens/sons

Não é necessário Java para esta versão. JavaScript é o que executa a interação no navegador; Python serve apenas como servidor local opcional.
